# 英単語テスト対策ノート（Vocab Typing Drill）

日本語の意味を見て英単語のスペルをタイピングで練習できる、単体HTMLの単語学習アプリです。ビルド不要・サーバー不要で、ファイルをブラウザで開くだけで動作します。

## 特徴

- **レッスン管理**：単元・回ごとに複数の単語リストを登録可能
- **表を貼り付けて単語登録**：Excel/スプレッドシートの「英単語」「意味」列をそのままコピー＆ペースト
- **フラッシュカード学習**：タップでカードを裏返して意味→英単語を確認、「覚えた／もう一度」で仕分け
- **タイピングテスト**：日本語の意味を見て英単語のスペルを入力、複数の意味（同義語）にも対応
- **わからない単語のスキップ**：スキップした単語は間違い扱いで記録され、後で復習できる
- **苦手単語の自動集計**：間違えた回数が多い単語を自動でリストアップし、まとめて復習可能
- **練習履歴**：レッスンごとに過去の練習結果を記録し、間違えた回だけ再挑戦できる
- **クラスの取り組み状況**：生徒名簿を登録すると、誰がそのレッスンに何回取り組んだかを一覧表示
- **先生用管理画面**：暗証番号で保護された管理画面からレッスン・生徒名簿を編集（簡易的な目隠しであり、強固な認証ではありません）

## 使い方

1. `vocab_typing_drill.html` をブラウザで開く（ローカルでもホスティングしても可）
2. 生徒画面の「先生用」から管理画面に入り、暗証番号を設定してレッスンと単語を登録
3. 生徒は自分の番号を入力し、レッスンを選んでフラッシュカードまたはテストで練習

## データの保存について

このアプリは [Claude Artifacts](https://claude.ai) の永続ストレージ機能（`window.storage`）を利用してレッスン・練習履歴・生徒名簿を保存します。そのため、GitHub Pages など Claude.ai 以外の環境にそのままホスティングした場合、保存機能は動作しない可能性があります。他の環境で動かす場合は、`window.storage` 部分を `localStorage` や自前のバックエンドに置き換えてください。
